# Serenade Singers — Application

Choir website with activity, event, class, member, and signup pages.

## Run from this directory

Use Node.js 22 and npm.

```bash
npm install
npm run dev
npm run lint
npm run build
```

Configure `NEXT_PUBLIC_APPS_SCRIPT_URL` and contact/social settings in `.env.local`. Verify form delivery against the deployed backend before opening membership registration.

For full project features, architecture, configuration, and limitations, see the [repository README](../README.md).
